# Zombot

A 2D action game created in Unity using C#.

## Description

Zombot is a pixel art 2D action game where the player controls a hero who can fight various enemies, and faces a boss at the end. The game features simple controls and engaging combat mechanics.

## Technologies Used

- **Unity** - Main game engine
- **C#** - Programming language for game logic
- **Cinemachine** - Smooth camera following
- **Animator & Sprite Renderer** - Character animations
- **Rigidbody2D & Collider2D** - Physics, collisions, and movement
- **Pixel Perfect Camera** - Sharp and clean sprite rendering
- **Git + GitHub** - Version control and project storage

## Controls

- **A / D** - Move left/right
- **Spacebar** - Jump
- **Left Shift** - Dash
- **J** - Attack

## Game Features

- Multiple enemy types: Goblin, Mushroom, FlyingEye, Assassin, Mage,...
- Boss fight: TheTarnishedWidow with special attacks and higher HP
- Win/Lose game states
- Pixel art graphics
- Smooth character movement and combat

## How to Run

1. Download the .zip files [here](https://github.com/NQKhanh296/Zombot/blob/58011f677c23554aa6ce1d8ce5f573ba7b699935/ZombotV2.zip)
2. Extract the .zip file
3. Run `Zombot.exe`
4. Use keyboard controls to play and fight enemies

## Code Structure

- **Enemy** - Base class for all enemies (movement, attacks, health)
- **Character** - Player base class (movement, damage)
- **SwordMaster** - Extends Character with attack and dash abilities
- **TheTarnishedWidow** - Boss class with special attacks
